# CEVHER: Maden Baronu

Dedesinden kalan madeni devralan mühendis Defne'nin, katları kazıp asansör ve taşıma zincirini
büyüterek bir maden imparatorluğu kurduğu idle/tycoon oyunu.

**Oyna:** https://ilerisoyomer34-coder.github.io/CrossyHop/

- Kaynak kod, testler ve belgeler: [`cevher/`](cevher/) — kurulum ve komutlar için
  [`cevher/README.md`](cevher/README.md)
- Tasarım dokümanı: [`cevher/docs/GDD.md`](cevher/docs/GDD.md)

Depo kökündeki `index.html` ve `assets/` oyunun yayın derlemesidir (`cevher` içinde
`npm run build:pages` ile üretilir). `sw.js`, bu adreste daha önce yayınlanan oyunun eski önbelleğini
temizleyip kendini kaldıran bir geçiş betiğidir.
